# Sistema Unidad Territorial — SUT

Proyecto Capstone de Ingeniería en Informática orientado a apoyar la gestión administrativa y comunitaria de una junta de vecinos.

## Objetivo

Mejorar la gestión de la unidad territorial de una junta de vecinos mediante una solución digital centralizada.

## Funcionalidades consideradas

- Gestión de vecinos.
- Certificados de residencia.
- Proyectos vecinales.
- Reservas de espacios.
- Actividades y control de cupos.
- Noticias y avisos.
- Usuarios, roles y permisos.

## Stack tecnológico

- Python
- Django
- PostgreSQL
- Bootstrap
- Git / GitHub

## Arquitectura

Aplicación web responsiva basada en un monolito modular Django conectado a PostgreSQL.
