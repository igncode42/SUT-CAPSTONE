# Evidencias — Sistema Unidad Territorial

Las evidencias se organizan por etapa para mantener la trazabilidad del proyecto.

## Histórico

`historico/` conserva evidencias de versiones anteriores:

- **01–16:** estado inicial;
- **17–25:** Fase 2.1.

Estas capturas muestran la evolución del proyecto y no necesariamente representan el estado actual del sistema.

Formato utilizado:

```text
NN-descripcion.png
```

Cada captura respalda un resultado concreto y evita duplicar información.

## Fuente de verdad

```text
Código → Pruebas → Jira → Evidencias → Documentación
```

Las capturas sirven como respaldo del estado verificado del proyecto, pero no reemplazan el código, las pruebas ni la documentación técnica.
