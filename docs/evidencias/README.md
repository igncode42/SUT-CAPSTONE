# Evidencias — Sistema Unidad Territorial

Las evidencias se conservan por checkpoint para mantener la trazabilidad del proyecto.

## Histórico

`historico/` contiene evidencias de versiones anteriores.

Las capturas 01–16 corresponden al estado inicial y las 17–25 a la Fase 2.1.

Estas evidencias muestran la evolución del proyecto, pero no representan necesariamente su estado actual.

## Fase 2.2

`fase-2.2/` contiene las evidencias verificadas de la Entrega 2.2.

Cada captura debe demostrar un resultado concreto y evitar duplicar información.

Formato:

```text
NN-descripcion.png
```

La evidencia final debe cubrir:

- estado técnico y pruebas;
- funcionalidades principales;
- seguridad e integridad;
- gestión y trazabilidad.

## Fuente de verdad

```text
Código → Pruebas → Jira → Evidencias → Documentación
```

Las capturas respaldan estos elementos, pero no los reemplazan.
